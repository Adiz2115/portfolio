Research Experience

Indian Institute of Technology Delhi2026 – present

Research with Prof. Maya Ramanath, Dept. of CSE

  • Vector search engines offer many index configurations (HNSW, IVFPQ, OPQ) that trade cost against fidelity, but deployments run every query on one configuration sized for the hardest queries. On 5.8M LAION items, running each query on its cheapest adequate configuration would roughly halve cost.
  • Fidelity is hard to predict before execution, since checking it needs the exact search the index exists to avoid. Borrowing synopses from relational query optimizers, the method splits the embedding space into cells around landmarks and records offline how often each configuration meets the target in each cell; at query time a nearest-landmark lookup gives a calibrated estimate and an optimizer picks a configuration within the workload's miss budget.
  • Across 16 embedding-model and query-direction settings, cost fell to a median 0.72× of a static deployment, with 21–32 µs lookups.

qwen-engine: CUDA inference for Qwen-Image on a 2 GB GPU2026

From-scratch C++/CUDA engine that runs Qwen-Image (7B diffusion transformer with an 8B vision-language encoder) for text-to-image and editing on a 2 GB laptop GPU, streaming weights layer by layer from SSD to pinned RAM to VRAM on overlapped CUDA streams, with custom quantized GEMM, attention, RoPE and convolution kernels. Validated stage by stage against the official pipeline (int8 output 35.4 dB PSNR). The most useful finding was a failure: 4-bit weights break the text encoder, because a few massive activations amplify quantization noise, while 8-bit does not.
